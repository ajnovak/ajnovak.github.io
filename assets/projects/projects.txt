# image: file | title | caption | overrides (category=, archive=yes, all=no)
# hidden: yes = not shown on the site (folder not added yet)
# view: full = the project page shows the full images, not the (cropped) thumbnails
# link: where the project lives; its label follows link_type:
#   (a .pdf link)  Read the full document (PDF)
#   plan           Read the plan
#   book           See the book
#   article        Read the article
#   award          See the award
#   (anything else) Visit the project page
# map: a live interactive map or story map; clicking the maps opens it
# map_label: optional wording for the map link (default: Open the interactive map / Open the story map)
# award: text | optional link; one line per award, listed under the title
# badge: a short award line for the project's card in the list
# card_video: clip.mp4 | poster.jpg (in thumbs/) = a muted loop in place of the cover,
#   on the project's card and as the first map on its page
# card_span: 2 or 3 = the project's card spans that many grid columns (for wide covers)
# card_column: 1, 2, or 3 = keep the card in that column of the grid (counted from the left) when the grid has that many
# zoom: no = the maps can't be opened full size (unreleased work); keep its full/ images out of the site
# lead: full = on the project page, the first map takes the full width on its own row
